Большое обновление: у EzPzDPI теперь есть окно, и программа сначала показывает, что именно не работает и почему, а уже потом чинит.

**Скачайте `EzPzDPI.exe`, запустите, нажмите «Проверить», затем «Починить».**

### Что нового

- **Диагноз по каждому сервису.** По умолчанию проверяются 16 сервисов: YouTube, Twitch, TikTok, Instagram и Facebook, X, Telegram, WhatsApp, Discord, звонки, Roblox, Steam, FACEIT, ChatGPT, сайты на Cloudflare, сайты на зарубежном хостинге и защищённый DNS. Ещё 15 включаются в настройках. Для каждого сервиса видно, что с ним:
  - работает;
  - заблокирован по имени сайта (обход поможет);
  - замедлен;
  - заблокирован по адресу (нужен VPN);
  - сам не работает с Россией;
  - провайдер подменяет адрес.
- **Видит другие обходы.** EzPzDPI находит zapret от Flowseal (с выбранным вариантом и режимами), zapret-win-bundle, zapret2, GoodbyeDPI, ByeDPI, SpoofDPI и Zapret GUI. Показывает, если две программы обхода работают одновременно или чужая служба падает. Умеет проверить без них, заменить их и вернуть их обратно.
- **Голос и звонки.** Оценка UDP по серии новых соединений и минуте наблюдения. Пинг роутера показывает, теряется ли связь ещё в вашем Wi-Fi.
- **Защищённый DNS.** На Windows 11 включается одной кнопкой, на Windows 10 есть инструкция для браузера. Без него YouTube и WhatsApp у многих провайдеров не откроются с 2026 года.
- **Безопасный подбор.** Пока идёт подбор, другие обходы только приостановлены. Обход не включится, если с ним перестали открываться обычные российские сайты. Если подбор прервался (отмена, сбой, выключение питания), всё возвращается как было.
- **Автопроверка при входе в Windows.** Если провайдер что-то поменял, EzPzDPI подберёт новый вариант. Программа не включает обход, который вы выключили сами.
- **Чистое удаление** через «Приложения» или из настроек. Возвращаются DNS, прокси и прежний обход. Резервные копии сохраняются в общих «Документах».
- **«Скопировать отчёт»** для вопросов на форуме: без IP-адресов и аккаунтов.

### Что проверено

- Сборка и тесты: юнит-тесты, Windows vet.
- Все 22 варианта zapret проходят `winws --dry-run` на Windows 11, в обычном и в игровом режиме.
- Сетевые проверки по всему каталогу на Windows 11, в сети без блокировок.
- Настоящее окно WebView2 на Windows 11: автотест сам нажимает «Проверить», получает диагноз, отрисовывает его и делает снимок.
- Задача автопроверки принята планировщиком Windows: проверено разбором её XML, без регистрации.
- Код проверен ревью по пяти направлениям, каждая находка подтверждена отдельным скептиком. Подтвердилось 50 находок, все исправлены. Повторная проверка исправлений нашла ещё 15 недочётов, они тоже исправлены.

### Что пока не проверено

- Режим с правами администратора на настоящем ПК: загрузка драйвера, подбор, служба, смена DNS, исключение Защитника, правка hosts.
- Работа у российских провайдеров.
- Windows 10.
