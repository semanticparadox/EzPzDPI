Исправление безопасности для 0.2.0.

- При удалении резервные копии (файл hosts, автозапуск прежнего обхода) раньше копировались в общую папку «Документы», куда может писать любой пользователь компьютера. Пользователь без прав администратора мог заранее подложить туда ссылку и перенаправить запись. Теперь копии сохраняются в новую папку `C:\ProgramData\EzPzDPI-backup-…` с непредсказуемым именем, доступную только администраторам. Ссылки при копировании не используются.
- Файл задачи автопроверки теперь создаётся в защищённой папке EzPzDPI, а не во временной папке пользователя.

Если у вас 0.2.0, просто скачайте новый `EzPzDPI.exe` и откройте его: программа обновит себя сама.

SHA-256 `EzPzDPI.exe`: см. `EzPzDPI.exe.sha256`.
